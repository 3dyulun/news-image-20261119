The world's news of Thursday 19 November 2026, summed up in one newspaper front page: the first-ever Xi, Trump and Putin trilateral summit in Shenzhen, GTA VI's global launch after 13 years, Van Gogh's $190.4M auction record, Iran's tanker-mine claims east of Hormuz, the ICJ's Rohingya verdict, Voyager 1 one light-day away, and a M5.7 quake in Kumamoto.

`main.py` copies `entry.png` to `/output/entry.png`. `build_frontpage.py` draws the front page from the verified stories (Pillow + Liberation/DejaVu fonts, run it again to regenerate `entry.png`).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
